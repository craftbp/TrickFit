# TricFit – Android app letöltése

**[⬇ A legfrissebb TricFit APK letöltése](https://github.com/craftbp/TrickFit/releases/latest/download/TricFit.apk)**

TricFit: edzésnapló, AI edzéstervek, étrend és kalóriaszámláló, edzők és edzőtermek, időpontfoglalás.
Weben (telefonon és számítógépen is): https://oldboy.tail276f17.ts.net/app/

## Telepítés
1. Töltsd le a fenti linkről a `TricFit.apk` fájlt a telefonodra.
2. Nyisd meg. Ha az Android rákérdez, engedélyezd a telepítést ebből a forrásból (böngésző / fájlkezelő).
3. Koppints a **Telepítés** gombra.

## Frissítés
Az app indításkor magától megnézi, van-e újabb verzió, és egy koppintással frissíthető
(Fiók → Beállítások → *App verzió* alatt kézzel is). Az edzéseid és beállításaid megmaradnak.

A korábbi verziók a [Releases](https://github.com/craftbp/TrickFit/releases) oldalon vannak (az utolsó 5).
